# Robotics Labs

Laboratory assignments for the Robotics course at Universidad Nacional de Colombia (UNAL).

---
## Lab Practices

| # | Practice | Description |
|---|----------|-------------|
| 1 | [ABB IRB140 – Drawing Tool](./IR-1-ABBIRB140-tool_calibration) | Design and calibration of a drawing tool for the ABB IRB140 industrial robot, with path simulation and real implementation. |
| 2 | [ABB IRB140 – Digital I/O](./IR-2-ABBIRB140-inputs_outputs) | Command robot paths using digital inputs and outputs on the ABB IRB140 with RAPID programming. |
| 3 | [ROS – Introduction](./ROS-1-Introduction) | Introduction to ROS concepts (nodes, topics, services) using the turtlesim package, with Python and MATLAB. |
| 4 | [ROS – PhantomX Forward Kinematics](./ROS-2-PhantomX-forward_kinematics) | Keyboard teleoperation of a PhantomX robot using ROS and forward kinematics. |
| 5 | [ROS – PhantomX Inverse Kinematics](./ROS-3-PhantomX-inverse_kinematics) | Pick and place operation with a PhantomX robot using inverse kinematics and ROS. |
